# Alias for UCRS.4b

`uml3b` is an alias for
[`UCRS.4b`](https://hreinwald.github.io/drc/reference/UCRS.4b.md).

## Usage

``` r
uml3b(names = c("b", "d", "e", "f"), ...)
```

## Arguments

- names:

  a vector of character strings giving the names of the parameters.

- ...:

  additional arguments passed to
  [`ucedergreen`](https://hreinwald.github.io/drc/reference/ucedergreen.md).
