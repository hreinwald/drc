# U-shaped Cedergreen-Ritz-Streibig model

`ucedergreen` provides a very general way of specifying the
Cedergreen-Ritz-Streibig modified log-logistic model for describing
u-shaped hormesis, under various constraints on the parameters.

## Usage

``` r
ucedergreen(
  fixed = c(NA, NA, NA, NA, NA),
  names = c("b", "c", "d", "e", "f"),
  method = c("loglinear", "anke", "method3", "normolle"),
  ssfct = NULL,
  alpha,
  fctName,
  fctText
)
```

## Arguments

- fixed:

  A numeric vector of length 5 specifying any parameters to be held
  fixed during the estimation. The order is `c(b, c, d, e, f)`. Use `NA`
  for parameters that should be estimated. The default is to estimate
  all parameters.

- names:

  A character vector of length 5 providing names for the parameters. The
  default is `c("b", "c", "d", "e", "f")`.

- method:

  A character string specifying the method for the self-starter function
  to use for finding initial parameter values. Options are
  `"loglinear"`, `"anke"`, `"method3"`, and `"normolle"`. This is only
  used if `ssfct` is `NULL`.

- ssfct:

  A custom self-starter function. If `NULL` (the default), a
  self-starter is automatically generated by calling
  [`cedergreen.ssf`](https://hreinwald.github.io/drc/reference/cedergreen.ssf.md)
  with the specified `method`, `fixed`, and `alpha` arguments.

- alpha:

  A mandatory numeric value specifying the fixed shape parameter
  \\\alpha\\. The function will stop if this is not provided.

- fctName:

  An optional character string to name the function object.

- fctText:

  An optional character string providing a descriptive text for the
  model.

## Value

A list of class `"UCRS"`, containing the model function (`fct`), the
self-starter function (`ssfct`), parameter names (`names`), and other
components required for use with modeling functions like
[`drm`](https://hreinwald.github.io/drc/reference/drm.md).

## Details

The u-shaped model is given by the expression \$\$f(x) = c + d -
\frac{d-c+f \exp(-1/x^{\alpha})}{1+\exp(b(\log(x)-\log(e)))}\$\$

The parameters are: `b`, the slope; `c`, the lower and `d` the upper
asymptote of the component that is mirrored in the U-shape (the curve
starts at \\2c\\ and approaches \\c + d\\); `e`, the location of the
transition; and `f`, the size of the hormetic deviation at low doses.
The wrappers
[`UCRS.4a`](https://hreinwald.github.io/drc/reference/UCRS.4a.md)-[`UCRS.5c`](https://hreinwald.github.io/drc/reference/UCRS.5c.md)
fix \\\alpha\\ at 1, 0.5 and 0.25 (suffix a, b, c) and, for the
four-parameter versions, `c` at 0.

## Examples

``` r
## Simulated U-shaped data: fit with drm() and plot
dose <- rep(c(0.1, 0.3, 1, 3, 10, 30, 100, 300), each = 3)
mu <- ucedergreen(alpha = 1)$fct(dose, matrix(c(1.5, 1, 6, 10, -2), length(dose), 5, byrow = TRUE))
dat <- data.frame(dose = dose, response = mu + 0.15 * sin(seq_along(dose) * 2.3))
m1 <- drm(response ~ dose, data = dat, fct = ucedergreen(alpha = 1))
plot(m1, type = "all", main = "U-shaped Cedergreen-Ritz-Streibig model")


## Effect of the asymptotes: fix c (lower) at 0 or d (upper) at 4
m.c0 <- drm(response ~ dose, data = dat, fct = ucedergreen(alpha = 1, fixed = c(NA, 0, NA, NA, NA)))
m.d4 <- drm(response ~ dose, data = dat, fct = ucedergreen(alpha = 1, fixed = c(NA, NA, 4, NA, NA)))
plot(m1, type = "all", main = "Fixed asymptotes")
plot(m.c0, type = "none", add = TRUE, col = "darkgreen")
plot(m.d4, type = "none", add = TRUE, col = "red")
legend("topleft", c("free", "c = 0", "d = 4"), col = c("black", "darkgreen", "red"),
  lty = 1, bty = "n")

```
