# Optimisation wrapper for drm

Optimisation wrapper for drm

## Usage

``` r
drmOpt(
  opfct,
  opdfct1,
  startVec,
  optMethod,
  constrained,
  warnVal,
  upperLimits,
  lowerLimits,
  errorMessage,
  maxIt,
  relTol,
  opdfct2 = NULL,
  parmVec,
  traceVal,
  silentVal = TRUE,
  matchCall
)
```
